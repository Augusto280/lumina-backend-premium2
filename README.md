# 🌸 Lumina IA Premium Backend

Backend oficial do aplicativo **Lumina IA**, com:
- Login e controle de assinaturas  
- Envio automático de e-mail via Gmail/SendGrid  
- Mensagens automáticas via WhatsApp (Z-API)  
- API REST pronta para deploy no Render

---

## 🚀 Deploy automático no Render
Clique no botão abaixo para fazer o deploy automático:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/augusto280/lumina-backend-premium)

> Substitua `SEU_USUARIO_GITHUB` pelo nome do seu usuário GitHub.

---

## 🔧 Variáveis de ambiente
| Variável | Descrição |
|-----------|------------|
| `PORT` | 10000 |
| `EMAIL_USER` | Seu e-mail Gmail |
| `EMAIL_PASS` | Senha de app do Gmail |
| `ZAPI_INSTANCE` | ID da sua instância Z-API |
| `ZAPI_TOKEN` | Token da API Z-API |
